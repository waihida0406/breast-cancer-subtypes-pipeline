# Outputs included in this download

Figures 1–11 and Tables 1–7 come from a run on the **real METABRIC data** (1,898 patients), using Step 0's cBioPortal download.

Steps 2, 3 and 8 (openFDA and ClinicalTrials.gov) could not reach those APIs where this package was prepared. Figures 12–14 and Tables 8–9 are therefore not included. Run `python run_pipeline.py` on your own computer to create them and to regenerate everything else.
